The Core Editor Team drives the WordPress block editor, also known as Gutenberg, the engine behind modern content creation.

If you have created a post, designed a page using blocks, or customised your website through the Site Editor, you have already experienced their work.

Start using the block editor today and take control of smarter, faster content creation.

The block editor brings a modern way to build interfaces in WordPress. It is powered by JavaScript and React, two technologies widely used across the web development industry.

Contributing to Gutenberg is not just about improving WordPress. It is also a strong opportunity to build in demand professional skills.

The team works openly on the Gutenberg GitHub repository, where contributors collaborate on new features, improvements, and bug fixes that eventually become part of WordPress core.

New contributors are always welcome. You can start small, explore the repository, and find multiple ways to get involved.

What Does the Core Editor Team Do?

The Core Editor Team builds and maintains the WordPress block editor, which powers the writing, editing, and site-building experience across the platform.

Their work includes:

  • Developing new editor features and blocks
  • Improving the Site Editor and block-based themes
  • Fixing bugs and improving usability
  • Maintaining editor APIs used by developers
  • Experimenting with new ideas before they reach WordPress core

Unlike WordPress core releases, the Gutenberg project moves at a much faster pace. The repository is updated regularly with frequent releases, giving contributors the chance to work in shorter development cycles and see their contributions go live faster.

You can explore how to contribute to the project here:

And check the development repository here:

https://github.com/WordPress/gutenberg

Key Responsibilities of the Core Editor Team

The Core Editor Team collaborates across a wide range of activities that support the ongoing development of Gutenberg.

Regular Activities

Contributors work on:

  • Developing new editor features and improvements
  • Fixing bugs and improving existing blocks
  • Reviewing pull requests and discussing solutions
  • Testing changes and reporting issues
  • Improving documentation and developer resources

Because Gutenberg development happens in GitHub, contributors often begin by exploring labeled issues.

For example:

  • Good First Issue – beginner-friendly contributions
  • Needs Testing – help verify fixes or improvements
  • Needs Design – opportunities for UX and design feedback

You can explore beginner-friendly issues here:

https://github.com/WordPress/gutenberg/issues?q=state%3Aopen%20label%3A%22Good%20First%20Issue%22

These labels make it easier for new contributors to find tasks that match their interests and experience.

Collaboration with Other Teams

The Core Editor Team works closely with several other Make teams, including:

  • Core – integrating Gutenberg improvements into WordPress releases
  • Design – improving the user experience of the editor
  • Accessibility – ensuring the editor remains usable for everyone
  • Performance – optimizing editor speed and efficiency
  • Test – validating changes before they reach production

This collaboration ensures that new editor features remain stable, accessible, and efficient.

Supporting New Contributors

The Gutenberg project is known for being welcoming to new contributors.

Many issues include detailed context, guidance, and suggestions for how to get started. Maintainers and experienced contributors actively help newcomers understand the codebase and the contribution process.

Because the editor is built using modern JavaScript frameworks, contributors can often apply skills they already use in other projects.

Challenges Faced by the Core Editor Team

Like any large open-source project, the Core Editor Team works through a number of challenges.

Technical Complexity

The Gutenberg codebase is large and constantly evolving. It includes:

  • JavaScript and React components
  • block APIs and editor infrastructure
  • integration with WordPress core

For new contributors, understanding the architecture may take some time.

Suggestion:
Start by exploring issues labeled Good First Issue or Needs Testing, and don’t hesitate to ask questions in the team’s Slack channel.

Rapid Development Cycle

Gutenberg releases happen more frequently than WordPress core releases. This rapid development pace is exciting, but it also requires contributors to stay aware of ongoing discussions and changes.

Suggestion:
Follow discussions in the repository and keep an eye on labeled issues to understand current priorities.

Collaboration Across Time Zones

Contributors work from all around the world, so communication often happens asynchronously through GitHub and Slack.

Suggestion:
Leave clear comments, ask questions when needed, and give others time to respond.

Growing with the Core Editor Team

Contributing to Gutenberg offers many opportunities for professional and personal growth.

Learn Modern Development Tools

Working on the editor helps contributors gain experience with:

  • JavaScript and React
  • modern UI development patterns
  • collaborative open-source workflows
  • large-scale codebase architecture

These skills are widely used across the web development industry.

Take on Greater Responsibilities

As contributors gain experience, they often move on to roles such as:

  • reviewing pull requests
  • mentoring new contributors
  • helping triage issues
  • contributing to feature design discussions

Contributor Days and WordCamps are excellent opportunities to connect with others working on the editor and learn directly from experienced contributors.

Stay Connected

The best place to connect with the team is the #core-editor channel in the WordPress Slack workspace.

Unlike some teams, the Core Editor Team does not hold regular scheduled meetings. Instead, conversations happen continuously in Slack and GitHub, where contributors ask questions, discuss ideas, and coordinate work.

Joining the channel is a great way to:

  • ask questions
  • follow ongoing discussions
  • learn about new issues and features
  • connect with other contributors
