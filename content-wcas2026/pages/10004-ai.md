## **Introduction**

Have you ever built an AI-powered feature that transformed how WordPress works under the hood? That’s the magic of the Core AI team – pioneering intelligent enhancements for WordPress Core on a global scale! The Core AI team integrates AI capabilities into WordPress Core, making it smarter, more intuitive, and future-ready for millions of users, developers, and site builders.

## **What Does the Core AI Team Do?**

The Core AI team ensures WordPress evolves with cutting-edge AI, embedding features like intelligent content suggestions, automated optimization, and predictive troubleshooting directly into Core.

As a new contributor, you can start by:

- Experimenting with AI prototypes in Core plugins or patches. Every idea or code snippet pushes AI integration forward.
- Reviewing AI-related tickets, offering feedback on feasibility or performance.
- Sharing insights from AI tools like LLMs to inspire Core enhancements.

The team’s innovations empower developers worldwide to build AI-native sites, automate workflows, and unlock new possibilities.

## **Your Path as a Contributor**

You don’t need to be an AI expert to join the Core AI team. Grow step by step:

- **Start small**. Tackle beginner-friendly tasks like testing AI-generated code suggestions or documentation for new AI hooks.
- **Build expertise**. Dive into advanced patches for features like AI-assisted block editing or performance tuning.
- **Lead the future**. Mentor others, propose AI roadmaps, or champion integrations with tools like Retrieval-Augmented Generation (RAG).

Every commit you make advances WordPress into an AI-powered era.

## **Overcoming Challenges Together**

AI in Core brings exciting complexities like ethical implementation, performance on diverse hosts, and privacy safeguards — but the team thrives on collaboration. It’s okay to iterate; propose ideas, test prototypes, and learn from feedback.

Team members rally around each other, so ping the channel if you need input on model fine-tuning or Core compatibility.\
Even suggesting an AI use case or linking relevant research is a powerful start.

## **Why Join the Core AI Team?**

- Master AI + WordPress. Hands-on work deepens skills in PHP, JS, LLMs, and Core architecture.
