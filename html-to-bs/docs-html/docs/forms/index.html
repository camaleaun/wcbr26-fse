Classes do input

Classe Efeito
.form-control Reset Bootstrap (borda, padding, font)
.newsletter__input Fundo $cream, borda sem radius, focus sem outline Bootstrap

Acessibilidade

O <label> usa .visually-hidden (Bootstrap) para ocultar visualmente mas manter acessível para leitores de tela. O for deve corresponder ao id do input.

O novalidate no <form> desabilita a validação nativa do browser — implemente validação em JS antes do envio.
