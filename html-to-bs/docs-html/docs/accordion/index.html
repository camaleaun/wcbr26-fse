Comportamento responsivo

Breakpoint Comportamento
< 640px Accordion com toggle (Bootstrap padrão)
≥ 640px Flex row, painéis sempre visíveis via CSS display:block !important

Em desktop, .fmt-head.accordion-button recebe pointer-events: none para desabilitar o toggle — os painéis ficam sempre abertos via override CSS.
