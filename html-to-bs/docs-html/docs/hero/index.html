Frame sticker duplo

.hero-frame — borda $teal-900 + sombra offset 5px. O ::before cria a moldura deslocada em $teal-700.

<div style="padding:2rem;max-width:300px"><div class="hero-frame"><img src="/img/hero.avif" alt="Belo Horizonte" width="512" height="512" class="img-fluid"/></div></div>
.hero-frame {
  position: relative;
  aspect-ratio: 1 / 1;
  isolation: isolate;
  border: 2px solid $teal-900;
  box-shadow: 5px 5px 0 0 $teal-900;

  &::before {
    content: "";
    position: absolute;
    inset: -16px 16px 16px -16px;
    border: 4px solid $teal-700;
    z-index: -1;
  }
}

isolation: isolate no .hero-frame garante que o ::before (z-index: -1) fique sobre o fundo da seção mas atrás da imagem.
