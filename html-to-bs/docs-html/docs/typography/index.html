Famílias

Duas fontes self-hosted em woff2 — declaradas em _fonts.scss, referenciadas pelas variáveis Bootstrap.

Variável SCSS Fonte Uso
$headings-font-family Poppins Títulos, nav, botões, badges
$font-family-sans-serif Montserrat Corpo de texto, tags, legenda

Títulos (display-*)

Bootstrap gera as classes .display-1 a .display-6. Nós definimos:

$headings-font-weight: 900;
$headings-color: $teal;

No design original, todos os títulos principais são text-transform: uppercase. Aplique a classe Bootstrap text-uppercase ou via SCSS.

Corpo de texto

$font-size-base: 1.125rem (18px) e $line-height-base: 1.45.

Parágrafo padrão — Montserrat 18px/1.45. A maior conferência WordPress da América Latina desembarca na capital mineira em 2026.

Texto secundário .text-muted — cor $muted (#556260).

<p class="mb-3">Parágrafo padrão — Montserrat 18px/1.45. A maior conferência WordPress da América Latina desembarca na capital mineira em 2026.</p><p class="text-muted">Texto secundário <code>.text-muted</code> — cor <code>$muted</code> (#556260).</p>
