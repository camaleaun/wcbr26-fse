The only form on the site is the **newsletter signup**: an email field and a submit button,
side by side on `md+`, stacked on mobile. It sits on a `$cyan-700` band.

## Newsletter

<div class="wcbrd-example p-4" style="background:var(--wcbr-primary)">
  <form class="d-flex flex-column flex-md-row gap-3">
    <label class="visually-hidden" for="nl-email">Your best email</label>
    <input class="form-control form-control-lg rounded-0 flex-grow-1" type="email" id="nl-email" placeholder="Your best email" autocomplete="email" />
    <button class="btn btn-orange btn-lg" type="submit">Subscribe</button>
  </form>
</div>

## Rules

- **Always label the field.** The visible design has no label, so use `.visually-hidden`.
  Never rely on a bare `placeholder` as the only description.
- **Square the corners.** `.rounded-0` matches the brand. The theme sets `$border-radius: 0`,
  so this is usually already the case.
- **Use `.btn-orange` for submit.** See [Buttons](/docs/2026/components/buttons).
- The input renders on `$sand-100` with `$gray-700` text. On focus the border goes white.

## Notes

- Keep `novalidate` on the form only if you handle validation yourself. Otherwise let the
  browser validate `type="email"` + `required`.
- For error and success states use the standard validation classes.
