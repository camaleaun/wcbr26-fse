The **Latest news** section is a grid of Bootstrap
[cards](https://getbootstrap.com/docs/5.3/components/card/). Each card has a linked image, a
[tag](/docs/2026/components/badges), a title that links to the article, a short excerpt, and a
"Read more" icon link.

## Anatomy

- **Media** — a linked, cropped image (`.card-img-top`, 16×9).
- **Tag** — an uppercase `$orange-600` label (see [Badges](/docs/2026/components/badges)).
- **Title** — `h3`, links to the article; hover turns it `$orange-600`.
- **Excerpt** — body copy.
- **Read more** — an icon link (`Read more →`).

## Markup

```html
<article class="card news-card h-100">
  <a href="#" class="ratio ratio-16x9 d-block">
    <img src="assets/img/news-convocacao.jpg" class="card-img-top object-fit-cover"
         alt="Microphone with a Call for Speakers sign in the background" width="512" height="320" loading="lazy">
  </a>
  <div class="card-body d-flex flex-column">
    <span class="tag mb-2">Call for Speakers</span>
    <h3 class="card-title h5">
      <a href="#" class="text-reset text-decoration-none">Call for Speakers is open!</a>
    </h3>
    <p class="card-text">Share your experience with the community. We are looking for new voices to take the stage.</p>
    <a href="#" class="icon-link mt-auto">
      Read more
      <svg viewBox="0 0 24 24" width="14" height="14" aria-hidden="true"><path d="M5 12h14M13 6l6 6-6 6" fill="none" stroke="currentColor" stroke-width="2"/></svg>
    </a>
  </div>
</article>
```

Wrap the cards in a responsive grid:

```html
<div class="row row-cols-1 row-cols-md-2 row-cols-lg-3 g-4">
  <div class="col"><!-- card --></div>
  <!-- … -->
</div>
```

## Mapping from the prototype

| `html-from-figma` | Bootstrap / WCBR |
|---|---|
| `.news-card` (article) | `.card.news-card` |
| `.news-card__media` (`a > picture`) | `.ratio.ratio-16x9` link + `.card-img-top` |
| `.news-card__body` | `.card-body` |
| `.tag` | `.tag` |
| `.news-card__title` (`h3 > a`) | `.card-title` + linked title |
| `p` | `.card-text` |
| `.link-under` (news variant) | `.icon-link` |
| `.news__grid` | `.row.row-cols-*` grid |

## Notes

- Keep `object-fit: cover` on the image so varied source ratios crop cleanly to 16×9.
- The news "Read more" link is plain teal text (no underline bar) — use `.icon-link`, not the
  underlined `.link-under` variant used elsewhere.
- Card titles use `$cyan-800`; the hover color is `$orange-600`.
