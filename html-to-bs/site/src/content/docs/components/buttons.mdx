The brand button treatment — square corners, heavy uppercase Poppins, a 2px border, and a
**hard offset shadow** that presses in on click — applies to both button variants:
`.btn-primary` and `.btn-orange`.

## Variants

| Class | Fill | Role |
|---|---|---|
| `.btn-primary` | `$cyan-700` `#00595d` | Standard primary action |
| `.btn-orange` | `$orange-600` `#c6360b` | The event CTA — tickets, newsletter |

There is **one** orange button, not several. See [Contrast](#contrast) for why.

<div class="wcbrd-example d-flex flex-wrap align-items-center gap-4">
  <a class="btn btn-primary" href="#">View schedule</a>
  <a class="btn btn-orange" href="#">Get your ticket</a>
</div>

Sizes are a separate concern — see [Sizing](#sizing) below.

## Contrast

The orange scale is not interchangeable for fills. Measured against white text:

| Token | Hex | vs. white | Usable as a fill? |
|---|---|---|---|
| `$orange-500` | `#f56530` | **3.09:1** | **No** — fails WCAG AA |
| `$orange-600` | `#c6360b` | 5.34:1 | Yes ✓ |

`$orange-500` is deliberately not used as a fill — at that contrast an automatic accessible-text
check would flip the label to **black**, and WCBR does not use black-on-orange. It stays an
accent for borders and sticker shadows only.

## The sticker shadow

The offset shadow is drawn from the variant's own border color, so it **recolors itself per
variant** automatically — no per-button CSS. Both variants are two-tone: the fill stays one
shade, the border (and therefore the shadow) sits a step darker or lighter — `$cyan-900` under
the `$cyan-700` fill for primary, `$orange-500` under the `$orange-600` fill for orange.

## Interaction

| State | Shadow | Transform |
|---|---|---|
| Rest | `5px 5px 0` | none |
| Hover | `3px 3px 0` | `translate(2px, 2px)` |
| Active | `0 0 0` | `translate(5px, 5px)` |
| Disabled | none | none |

## Sizing

There are two sizes. Base `.btn` is the smaller one — the navbar "Ingressos" CTA is the only
place it appears. `.btn-lg` is the bigger sticker CTA used everywhere else (hero, sponsor,
newsletter, drawer).

<div class="wcbrd-example d-flex flex-wrap align-items-center gap-4">
  <a class="btn btn-orange fw-black" href="#">Tickets</a>
  <a class="btn btn-orange btn-lg" href="#">Get your ticket</a>
</div>

`.btn-lg` carries its own weight (900) automatically; the base size needs `.fw-black` added
when it should look just as heavy.

The sponsor CTA ("Torne-se um patrocinador") is one deliberate divergence from the prototype:
it's rendered in the primary cyan instead of the ticket orange, to separate a general-interest
action from ticket/newsletter CTAs — see the [Variants](#variants) note above.

## Notes

- Do not round the corners — square corners are intentional and brand-defining.
- Labels are uppercase Poppins 900; keep them short and imperative.
- `.btn-primary` is **cyan**, not orange. Use `.btn-orange` for the ticket CTA.
