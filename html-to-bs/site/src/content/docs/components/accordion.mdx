The **What to expect** (formats) section is an accordion: each session format is a
collapsible item with a leading icon, an uppercase heading, and a body of copy.

## Structure

Each item is a collapsible block: a header button (which carries the built-in caret) and a
collapsible body. The prototype's custom caret (`.fmt__caret`) is dropped — the header button
draws its own. The leading icon is kept as a `<span>` before the label.

The icon takes one of three color modifiers: `.format-icon-cyan`, `.format-icon-orange`, or
`.format-icon-panel`. On `sm+`, `.formats-accordion` lays the three items out side by side and
keeps every panel open.

Only one item opens at a time, matching the prototype — that's controlled per group, so
dropping the group link opens the door to multiple panels open at once if ever needed.

## Notes

- Headings sit inside the button; keep them as `h3` for the document outline.
