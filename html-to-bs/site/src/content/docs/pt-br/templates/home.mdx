## De custom CSS para Bootstrap utilities

Tabela de classes da versão Figma (`html-from-figma`) mapeadas para o equivalente Bootstrap em `html-to-bs`:

| Figma custom | Bootstrap / WCBR |
|---|---|
| `.skip-link` | `.visually-hidden-focusable` |
| `.site-header` | `.site-header.sticky-top.border-bottom` |
| `.header__nav ul` | `.nav.header-nav.d-none.d-xl-flex` |
| `.nav__item--has-sub` | `.nav-item.dropdown` + `.dropdown-menu` |
| `data-drawer-*` (JS customizado) | `data-bs-toggle="offcanvas"` / `data-bs-dismiss` |
| `.nav__sub` (drawer customizado) | `.offcanvas.offcanvas-end` + `.collapse` |
| `.btn--sm` | `.btn.btn-sm` |
| `.hero-lead` | `.lead` |
| `.stat-num.d-block` | `.stat-number.d-block` (cor no SCSS) |
| `.stat-label.d-block` | `.stat-label.d-block` (cor + uppercase no SCSS) |
| `.news-card` | `.card.news-card` (base Bootstrap + override de cor) |
| `.footer__col-list` | `.footer-col-list` (flex column + gap no SCSS) |
| `.organizer__role` | `.organizer-role` (uppercase no SCSS) |

## Componentes Bootstrap nativos usados

### Header / Navbar

O header do Figma era um bloco totalmente customizado. No Bootstrap usa `navbar` com `dropdown` nativo para desktop e `offcanvas` para mobile — sem JS manual.

```html
<header class="site-header sticky-top border-bottom">
  <nav class="navbar" aria-label="Navegação principal">
    <div class="container">

      <a class="navbar-brand" href="#">
        <img src="assets/img/logo.avif" alt="WordCamp Brasil 2026" width="260" height="102" fetchpriority="high" class="header-logo">
      </a>

      <!-- Desktop: d-none abaixo de xl -->
      <ul class="nav header-nav d-none d-xl-flex ms-4">
        <li class="nav-item dropdown">
          <a class="nav-link dropdown-toggle" href="#sobre" data-bs-toggle="dropdown" aria-expanded="false">Evento</a>
          <ul class="dropdown-menu">
            <li><a class="dropdown-item" href="#sobre">Sobre o evento</a></li>
          </ul>
        </li>
        <li class="nav-item"><a class="nav-link" href="#formatos">Agenda</a></li>
      </ul>

      <a class="btn btn-primary btn-sm d-none d-xl-inline-flex ms-3" href="#">Ingressos</a>

      <!-- Hambúrguer mobile -->
      <button class="navbar-toggler d-xl-none ms-auto" type="button"
              data-bs-toggle="offcanvas" data-bs-target="#mobile-drawer"
              aria-controls="mobile-drawer" aria-label="Abrir menu">
        <span class="navbar-toggler-icon"></span>
      </button>

    </div>
  </nav>
</header>
```

### Accordion — O que esperar

Responsivo: no mobile é um accordion colapsável; acima de `sm` vira três cards lado a lado (via media query em SCSS). O `data-bs-parent` não é usado para permitir múltiplos painéis abertos.

```html
<div class="accordion formats-accordion" id="formatsAccordion">
  <article class="accordion-item format">
    <h3 class="accordion-header">
      <button class="accordion-button format-head collapsed" type="button"
              data-bs-toggle="collapse" data-bs-target="#format-panel-1" aria-expanded="false">
        <span class="format-icon format-icon-cyan" aria-hidden="true"><!-- svg --></span>
        <span class="format-title">Palestras</span>
      </button>
    </h3>
    <div class="accordion-collapse collapse" id="format-panel-1" data-bs-parent="#formatsAccordion">
      <div class="accordion-body">Sessões de 40 minutos...</div>
    </div>
  </article>
</div>
```

## DNA visual WCBR — CSS genuinamente customizado

Os componentes abaixo **não podem** ser substituídos por utilities Bootstrap — são a identidade visual do evento:

| Classe | Por quê permanece em SCSS |
|---|---|
| `.btn`, `.btn-orange` | Sticker flat style: `box-shadow: 5px 5px 0 0` (cor da própria variante), hover `transform: translate` |
| `.link-under` | Underline animado: transição de `gap` no hover |
| `.badge` | Tratamento de marca (Poppins, uppercase) — cor via `.text-bg-*` |
| `.hero-frame` | `aspect-ratio: 1/1` + borda decorativa `::before` + shadow offset |
| `.about-media` | `aspect-ratio: 584/428` + shadow offset `$orange` |
| `.format`, `.format-head`, `.format-icon` | Override do accordion: sticker com shadow, icon box `place-items: center` |
| `.sponsor`, `.tier` | Sticker box + divisor com `::before`/`::after` |
| `.avatar` + variantes | Círculo com `border-color` temática |
| `.social-icon`, `.icon` | SVG inline: `fill: currentColor` com dimensões fixas |
| `.section` | `padding-block: clamp(64px, 9vw, 102px)` — sem utility Bootstrap equivalente |

## Acessibilidade

- Skip link: `.visually-hidden-focusable` (substitui o `.skip-link` customizado)
- `aria-labelledby` em todas as `<section>` com `id` correspondente no heading
- `aria-hidden="true"` em todos os SVGs decorativos
- `aria-current="page"` no item ativo do drawer mobile
- `aria-expanded` gerenciado automaticamente pelo JS do Bootstrap (dropdown, collapse, offcanvas)
