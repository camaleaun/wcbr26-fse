## Estrutura

### Header / Navbar

O header do Figma era um bloco totalmente customizado. O build usa uma navbar padrão com
dropdowns no desktop e um drawer offcanvas no mobile, sem JS manual. Veja
[Navbar](/docs/2026/components/navbar) para o detalhamento completo.

### Hero

Duas colunas, imagem de um lado, heading/lead/CTA do outro, centralizados verticalmente.

### Accordion, o que esperar

Responsivo. No mobile é um accordion colapsável. Acima de `sm` vira três cards lado a lado, via
media query em SCSS. Múltiplos painéis podem ficar abertos ao mesmo tempo. Veja
[Accordion](/docs/2026/components/accordion).

### Cards de notícias

Uma grade responsiva de cards, três colunas no máximo. Cada card usa `.card.news-card.h-100`.
A base do card fornece `display: flex; flex-direction: column`, então o link "Leia mais" fica
fixado no rodapé com `mt-auto`. Veja [Cards](/docs/2026/components/cards).

O DNA visual do evento é feito à mão e genuinamente customizado: as sombras sticker, underlines
animados, tratamento de badge, molduras decorativas de mídia e estilos de
accordion/patrocinador/avatar. Nada disso vem de utility classes prontas.

## Acessibilidade

- Skip link: `.visually-hidden-focusable` (substitui o `.skip-link` customizado)
- `aria-labelledby` em todas as `<section>` com `id` correspondente no heading
- `aria-hidden="true"` em todos os SVGs decorativos
- `aria-current="page"` no item ativo do drawer mobile
- `aria-expanded` gerenciado automaticamente pelo comportamento interativo do site (dropdown,
  collapse, offcanvas)
