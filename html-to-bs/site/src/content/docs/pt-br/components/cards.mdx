A seção **Últimas notícias** é uma grade de cards. Cada card tem uma imagem vinculada, uma
[tag](/docs/2026/components/badges), um título que linka para o artigo, um trecho curto e um
link "Leia mais" com ícone.

## Anatomia

- **Mídia** — imagem recortada e vinculada (16×9).
- **Tag** — rótulo maiúsculo `$orange-600` (veja [Badges](/docs/2026/components/badges)).
- **Título** — linka para o artigo; hover vira `$orange-600`.
- **Trecho** — corpo do texto.
- **Leia mais** — link com ícone (`Leia mais →`).

## Notas

- Mantenha `object-fit: cover` na imagem para que variações de proporção recortem corretamente em 16×9.
- O link "Leia mais" das notícias é texto ciano simples (sem barra de sublinhado) — use `.icon-link`, não a variante sublinhada `.link-under` usada em outros lugares.
- Títulos de card usam `$cyan-800`; a cor de hover é `$orange-600`.
