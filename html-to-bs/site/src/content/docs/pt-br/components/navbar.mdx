O cabeçalho do site tem logo, menu horizontal com dropdowns, meta do evento (redes sociais, hashtags, data) e o CTA de *Ingressos*. Abaixo de `xl` o menu recolhe em um drawer offcanvas.

## Estrutura

O cabeçalho é uma barra fixa com borda inferior. Dentro dela: o logo da marca, uma lista de navegação horizontal (visível de `xl` pra cima) com dois itens de dropdown ("Evento" e seu submenu), o CTA de *Ingressos*, e um toggler de menu que só aparece abaixo de `xl`.

## Dropdowns

Os submenus do desktop abrem no clique, não no hover como o protótipo. O próprio botão de
toggle desenha o caret, então o SVG artesanal do protótipo foi removido.

Links de nav são Poppins 700 maiúsculo em `$cyan-700`, com borda inferior transparente de 3px que fica laranja no hover.

## Drawer offcanvas

No mobile o menu vira um painel offcanvas que abre pelo lado. O submenu "Evento" do cabeçalho vira uma sublista recolhível dentro do drawer, acionada pelo próprio botão.

O caret do drawer gira 180° quando seu controle está expandido. Isso é acionado puramente por
`[aria-expanded="true"]`, sem JavaScript próprio.

## Notas

- Todo o JavaScript customizado do drawer foi substituído por atributos data declarativos. O site não embarca nenhum script de nav próprio.
- Mantenha `aria-label` no link de marca e no toggler. A imagem do logo carrega o texto alternativo.
- O cabeçalho fica fixo no topo (`.sticky-top`) com borda inferior, sobre `$sand-100`.
