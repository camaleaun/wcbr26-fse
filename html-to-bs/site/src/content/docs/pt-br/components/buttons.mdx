O tratamento de marca dos botões — cantos retos, Poppins maiúsculo em peso 900, borda de 2px e uma **sombra offset rígida** que afunda no clique — é aplicado às duas variantes: `.btn-primary` e `.btn-orange`.

## Variantes

| Classe | Preenchimento | Função |
|---|---|---|
| `.btn-primary` | `$cyan-700` `#00595d` | Ação primária padrão |
| `.btn-orange` | `$orange-600` `#c6360b` | CTA do evento — ingressos, newsletter |

Existe **um** botão laranja, não vários. Veja [Contraste](#contraste) para entender o porquê.

<div class="wcbrd-example d-flex flex-wrap align-items-center gap-4">
  <a class="btn btn-primary" href="#">Ver agenda</a>
  <a class="btn btn-orange" href="#">Ingressos</a>
</div>

Tamanhos são uma questão separada — veja [Tamanhos](#tamanhos) abaixo.

## Contraste

A escala orange não é intercambiável para preenchimentos. Medida contra texto branco:

| Token | Hex | vs. branco | Usável como preenchimento? |
|---|---|---|---|
| `$orange-500` | `#f56530` | **3.09:1** | **Não** — reprovado no WCAG AA |
| `$orange-600` | `#c6360b` | 5.34:1 | Sim ✓ |

`$orange-500` deliberadamente não é usado como preenchimento — nesse contraste, uma checagem automática de texto acessível viraria o rótulo para **preto**, e o WCBR não usa preto sobre laranja. Ele permanece como acento para bordas e sombras de sticker.

## A sombra sticker

A sombra offset é derivada da cor de borda da própria variante, então ela **se recolore por variante** automaticamente — sem CSS por botão. Ambas as variantes são bicolores: o preenchimento fica em um tom, a borda (e portanto a sombra) fica um passo mais escura ou mais clara — `$cyan-900` sob o preenchimento `$cyan-700` na primária, `$orange-500` sob o preenchimento `$orange-600` na laranja.

## Interação

| Estado | Sombra | Transform |
|---|---|---|
| Repouso | `5px 5px 0` | nenhum |
| Hover | `3px 3px 0` | `translate(2px, 2px)` |
| Ativo | `0 0 0` | `translate(5px, 5px)` |
| Desabilitado | nenhum | nenhum |

## Tamanhos

Existem dois tamanhos. O `.btn` base é o menor — o CTA "Ingressos" da navbar é o único lugar onde aparece. `.btn-lg` é o CTA sticker maior, usado em todo o resto (hero, patrocinador, newsletter, drawer).

<div class="wcbrd-example d-flex flex-wrap align-items-center gap-4">
  <a class="btn btn-orange fw-black" href="#">Ingressos</a>
  <a class="btn btn-orange btn-lg" href="#">Garanta seu ingresso</a>
</div>

`.btn-lg` já traz o peso (900) sozinho; o tamanho base precisa de `.fw-black` quando também precisar parecer pesado.

O CTA de patrocinador ("Torne-se um patrocinador") é uma divergência deliberada do protótipo:
é renderizado no ciano primário em vez do laranja de ingresso, pra separar uma ação de
interesse geral dos CTAs de ingresso/newsletter — veja a nota em [Variantes](#variantes) acima.

## Notas

- Não arredonde os cantos — `$border-radius: 0` é intencional e parte da identidade visual.
- Rótulos são Poppins 900 maiúsculo; mantenha-os curtos e imperativos.
- `.btn-primary` é **ciano**, não laranja. Use `.btn-orange` para o CTA de ingressos.
