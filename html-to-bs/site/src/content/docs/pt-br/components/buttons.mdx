O WCBR usa o componente `.btn` do Bootstrap sem alterações estruturais. O tratamento de marca — cantos retos, Poppins maiúsculo em peso 900, borda de 2px e uma **sombra offset rígida** que afunda no clique — é aplicado ao `.btn` base, então **todas** as variantes herdam: `.btn-primary`, `.btn-orange`.

## Variantes

`orange` é adicionado a `$theme-colors`, então o Bootstrap poderia gerar sua família completa
(`.btn-outline-orange`, `.bg-orange`, `.text-orange`, `.border-orange`, `.link-orange`, …)
como as cores nativas — mas o build só entrega as duas variantes que o protótipo realmente usa
(veja [Build Pipeline](/docs/2026/getting-started/build-pipeline)).

| Classe | Preenchimento | Função |
|---|---|---|
| `.btn-primary` | `$cyan-700` `#00595d` | Ação primária padrão |
| `.btn-orange` | `$orange-600` `#c6360b` | CTA do evento — ingressos, newsletter |

Existe **um** botão laranja, não vários. Veja [Contraste](#contraste) para entender o porquê.

<div class="wcbrd-example d-flex flex-wrap align-items-center gap-4">
  <a class="btn btn-primary" href="#">Ver agenda</a>
  <a class="btn btn-orange" href="#">Ingressos</a>
</div>

```html
<a class="btn btn-primary" href="#formatos">Ver agenda</a>
<a class="btn btn-orange" href="#ingressos">Ingressos</a>
```

Tamanhos são uma questão separada — veja [Tamanhos](#tamanhos) abaixo.

## Contraste

A escala orange não é intercambiável para preenchimentos. Medida contra texto branco:

| Token | Hex | vs. branco | Usável como preenchimento? |
|---|---|---|---|
| `$orange-500` | `#f56530` | **3.09:1** | **Não** — reprovado no WCAG AA |
| `$orange-600` | `#c6360b` | 5.34:1 | Sim ✓ |

`$orange-500` é deliberadamente **não** registrado em `$theme-colors`. Se estivesse, o `color-contrast()` do Bootstrap viraria o rótulo para **preto** — e o WCBR não usa preto sobre laranja. Ele permanece como acento para bordas e sombras de sticker.

## A sombra sticker

A sombra offset é derivada da cor de borda da própria variante
(`--wcbr-btn-border-color`), então ela **se recolore por variante** — sem CSS por botão.

```scss
.btn {
  box-shadow: $btn-sticker-offset $btn-sticker-offset 0 0 var(--#{$prefix}btn-border-color);
}
```

Ambas as variantes são bicolores: o preenchimento fica em um tom, a borda (e portanto a sombra) fica um passo mais escura ou mais clara.

```scss
.btn-primary {
  --#{$prefix}btn-border-color: #{$cyan-900};         // #003e3e
  --#{$prefix}btn-hover-border-color: #{$cyan-900};
}

.btn-orange {
  --#{$prefix}btn-border-color: #{$orange-500};       // #f56530
  --#{$prefix}btn-hover-border-color: #{$orange-500};
}
```

## Interação

| Estado | Sombra | Transform |
|---|---|---|
| Repouso | `5px 5px 0` | nenhum |
| Hover | `3px 3px 0` | `translate(2px, 2px)` |
| Ativo | `0 0 0` | `translate(5px, 5px)` |
| Desabilitado | nenhum | nenhum |

## Tamanhos

O protótipo só usa dois tamanhos. O `.btn` base é o menor — o CTA "Ingressos" da navbar é o
único lugar onde aparece. `.btn-lg` é o CTA sticker maior, usado em todo o resto (hero,
patrocinador, newsletter, drawer). Não existe `.btn-sm`: nada no protótipo precisa de um
terceiro tamanho, menor ainda.

<div class="wcbrd-example d-flex flex-wrap align-items-center gap-4">
  <a class="btn btn-orange" href="#">Ingressos</a>
  <a class="btn btn-orange btn-lg" href="#">Garanta seu ingresso</a>
</div>

```html
<a class="btn btn-orange" href="#ingressos">Ingressos</a>
<a class="btn btn-orange btn-lg" href="#ingressos">Garanta seu ingresso</a>
```

```scss
$btn-font-family:  $headings-font-family;  // Poppins
$btn-font-weight:  900;
$btn-border-width: 2px;

$btn-padding-y:    .8125rem;  // 13px — base
$btn-padding-x:    1.875rem;  // 30px
$btn-font-size:    .9rem;

$btn-padding-y-lg: 1.25rem;   // 20px — .btn-lg
$btn-padding-x-lg: 2.5rem;    // 40px
$btn-font-size-lg: 1.05rem;
```

## Mapeamento do protótipo

O `html-from-figma` usa a mesma nomenclatura de tamanho `.btn`/`.btn-lg` do build WCBR — `.btn`
sozinho é o CTA pequeno da navbar, `.btn-lg` é o CTA sticker grande.

| `html-from-figma` | Bootstrap / WCBR |
|---|---|
| `.btn` | `.btn.btn-orange` |
| `.btn-lg` | `.btn.btn-orange.btn-lg` |
| `.btn-brick` | `.btn-orange` (consolidado) |
| `.header__ingressos` | `.btn.btn-orange` na navbar |
| `.drawer__cta` | `.btn.btn-orange.btn-lg` dentro do offcanvas |

O CTA de patrocinador ("Torne-se um patrocinador") é a única divergência deliberada: o
protótipo mantém laranja/brick como todo o resto, mas o WCBR renderiza `.btn.btn-primary.btn-lg`
(ciano) para separá-lo dos CTAs de ingresso/newsletter — veja a nota em [Variantes](#variantes)
acima.

## Notas

- Não arredonde os cantos — `$border-radius: 0` é intencional e parte da identidade visual.
- Rótulos são Poppins 900 maiúsculo; mantenha-os curtos e imperativos.
- `.btn-primary` é **ciano**, não laranja. Use `.btn-orange` para o CTA de ingressos.
