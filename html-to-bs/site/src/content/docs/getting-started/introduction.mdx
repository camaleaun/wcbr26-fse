The **WCBR Design System** (`wcbrbs`) is the visual language of WordCamp Brasil 2026. It
ships the event's colors, typography, and page sections as reusable tokens and ready-to-use
markup, so every surface looks and behaves like one product.

## What it is

- **Token-driven.** Colors and type come from a single Sass source
  (`scss/_variables.scss`) that mirrors the Figma **WCBR** variable collection.
- **Minimal by design.** Only the styles the prototype actually uses ship. Nothing
  speculative, nothing unused.
- **Sharp and editorial.** Border-radius is `0` across the board, headings use **Poppins 900**
  uppercase, body copy uses **Montserrat** at an 18px base.

## What it is built on

| Layer | Choice |
|---|---|
| CSS prefix | `wcbr-` (e.g. `--wcbr-primary`) |
| Body font | Montserrat |
| Heading font | Poppins (weight 900) |
| Base font size | 1.125rem (18px) |
| Border radius | 0 (all sizes) |
| Primary | `$cyan-700` · `#00595d` |
| Secondary | `$orange` · `#e84814` |

## Source of truth

The current source of truth is **`html-from-figma`**, the hand-built prototype of the 2026
home page, distilled directly from the Figma design. This documentation covers only what that
prototype actually contains.

The prototype is composed of these sections, each becoming a documented component:

- **Header**: sticky navbar with dropdowns, a mobile offcanvas drawer, social links, and the *Ingressos* CTA.
- **Hero**: title, lead, chips, and primary CTA.
- **Stats**: the event numbers bar.
- **About**: intro copy block.
- **Formats**: an accordion of session formats.
- **News**: a grid of news cards.
- **Sponsors**: sponsor logo wall.
- **Organization**: organizer avatars.
- **Newsletter**: the signup form.
- **Footer**: link columns and social.
