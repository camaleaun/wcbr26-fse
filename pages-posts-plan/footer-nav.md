## Proposta WCBR2026

Rodapé com 3 grupos: eventos maiores são minimalistas, mas o WCBR tem audiência local que usa o rodapé para descoberta.

|---|---|---|

### Decisões para o WCBR2026

| Questão | Opções | Ref. |
|---|---|---|
| Newsletter no rodapé? | Sim (como WCEU+WCUS) / Não | WCBR2025 não tinha |
| Patrocinadores no rodapé? | Sim (WCBR2025 tinha) / Não (WCEU+WCUS não têm) | Pode substituir pelo logo |
| Redes sociais no rodapé? | Ícones de redes / Texto / Não listar | WCAS tem texto, outros usam ícones no rodapé |
| Palestrantes no rodapé? | Sim (WCBR2025 tinha) / Não (WCEU+WCUS não têm) | Depende de ter conteúdo rico |
| Quantos grupos? | 2 (minimalista como WCEU) / 3 (balanceado) | 3 é bom para visibilidade |
